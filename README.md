Manage appointments, capacity, reminders, no-shows, waitlists, and customer follow-up.

## Features

- **Appointment Management** — Create, reschedule, and cancel bookings
- **Capacity Tracking** — Monitor slot availability and occupancy
- **Customer Profiles** — Track booking history and follow-up status
- **Status Pipeline** — Confirmed, pending, completed, and no-show tracking
- **Search & Filter** — Find bookings by status, date, or customer
- **Analytics View** — Booking distribution and capacity insights
- **Import / Export** — JSON-based data portability

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Markup | HTML5 |
| Styling | CSS3 (Custom Properties, Grid, Flexbox) |
| Logic | Vanilla JavaScript (ES2022) |
| Storage | LocalStorage |
| Server | Python HTTP server (dev) |

## Getting Started

### Prerequisites

- Python 3.x (for dev server)
- Modern web browser

### Installation

```bash
git clone https://github.com/vizvasanlya/First.git
cd First/vizvasanlya-booking-system
```

### Run

```bash
npm start
```

Open [http://localhost:5173](http://localhost:5173)

### Docker

```bash
docker compose up --build
```
